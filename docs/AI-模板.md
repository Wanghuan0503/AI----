# AI 输出模板（参考层 · 按需加载）

> 常驻规则在 `AGENTS.md`。**只在要出计划、要写变更说明、要上报阻塞、要记风险时读本文件。**
> 用法：直接复制对应模板填空，不要自由发挥格式。

---

## 1. PLAN — 变更计划（R2+ 动手前必须输出）

```markdown
## 变更计划（PLAN）

**任务**：<一句话目标>
**类型/等级**：<缺陷修复/新功能/…>｜R<?>
**命中停止条件**：无 / STOP-<n>（说明）
**当前状态**：待确认 / 已确认（确认原话：…）

### 1. 目标
- <可验证的目标>

### 2. 非目标（本次不做）
- <明确排除，防止范围蔓延>

### 3. 现状分析（带证据）
- 入口：`path/file.ext:123`
- 调用链：`A() -> B() -> C()`（证据：文件:行号）
- 现有测试：`tests/xxx_test.py::test_yyy`
- 历史原因：`git log -p -- path` 的结论

### 4. 变更点
| # | 文件:位置 | 变更内容 | 原因 | 语义影响 |
|---|-----------|----------|------|----------|
| 1 | `src/a.py:88` | 增加空值判断 | 上游可能返回 None | 返回 400 而非 500 |

### 5. 影响面（9 维度，不涉及写"不涉及"）
调用方 / 数据 / 接口契约 / 行为（默认值·错误码·幂等·并发）/ 性能 / 安全 / 部署 / 用户可见 / 可观测

### 6. 风险与缓解
| 风险 | 可能性 | 影响 | 缓解措施 |
|------|--------|------|----------|

### 7. 验证方式
- 目标场景：`<命令>` → 预期 <…>
- 边界场景：<空/极值/并发/超时/异常/权限> → `<命令>` → 预期 <…>
- 回归场景：`<命令>` → 预期 <…>
- 无法执行项：`<命令>`（原因 <…>，需人类验证）

### 8. 回滚方案
- 方式：<revert 提交 / 关开关 / 反向脚本>
- 命令：`<具体命令>`　回滚后验证：`<命令>` → 预期 <…>
- 数据回滚：<有/无 + 步骤>

### 9. 不确定与假设
- 【假设】<内容>（依据 <…>；不成立则影响 <…>）
- 【未知】<内容>（获取方式 <…>）

### 10. 需要的确认
- 请确认：<一个明确的选择题，选项 A/B>
```

## 2. CHANGE — 变更说明（交付时输出）

```markdown
## 变更说明（CHANGE）

**变更摘要**：<一句话>
**等级**：R<?>　**确认记录**：<人类确认原话与时间>

### 1. 为什么改（根因）
- 现象：<可观测现象>
- 机制（根因）：<为什么会发生，链路/条件/触发点>
- 证据：`<命令>` 输出 / `文件:行号`

### 2. 改了什么（逐点含语义）
| # | 文件:行号 | 变更 | 之前语义 | 之后语义 |
|---|-----------|------|----------|----------|

### 3. 怎么验证（真实执行）
| 场景 | 命令 | 真实输出 | 结论 |
|------|------|----------|------|
| 目标 | | | |
| 边界 | | | |
| 回归 | | | |
- 未运行的验证：`<命令>`（原因 <…>，请人类执行）

### 4. 哪里不确定（残余风险）
- 【未验证】<…>　【未覆盖】<场景>　【假设】<…>
- 已知限制与可能副作用：

### 5. 人类需要做什么（认知对齐）
- 建议重点评审：`文件:行号`（关注点 <…>）
- 三分钟原理说明：<数据流/时序/最小例子>

### 6. 回滚
- 命令：`<…>`　回滚后预期：<…>

### 7. 遗留与后续
- 遗留问题 / 后续建议 / 待补测试或文档
```

## 3. BLOCK — 阻塞上报（停止条件触发 / 同因失败 2 次）

```markdown
## 阻塞上报（BLOCK）

**触发条款**：STOP-<?> / 红线 <?>
**问题一句话**：<…>
**同因失败次数**：<n>

### 1. 已尝试方案与结果
| # | 假设 | 动作 | 证据（命令/输出/文件:行号） | 结果 | 假设是否被否证 |
|---|------|------|------------------------------|------|----------------|

### 2. 当前认知
- 已验证事实：<…>
- 已被否证的假设：<…>
- 仍成立的假设：<…>
- 未知：<…>

### 3. 剩余分支方案（每项含代价）
- 方案 A：<做法>｜预期效果｜代价｜风险｜回滚难度
- 方案 B：<…>
- 方案 C：<…>

### 4. 需要人类决策
- 决策问题（选择题）：<…>
- 或需要人类提供：<信息/权限/环境/账号>
- 不决策的后果：<…>

### 5. AI 不再做的事
- <明确声明停止哪些试错动作，避免循环>
```

## 4. RISK — 风险标注

```markdown
## 风险标注（RISK-<id>）

**等级**：R<?>　**位置**：`文件:行号`　**发现方式**：<…>
**描述**：<风险是什么，触发条件是什么>
**影响**：<数据/安全/资金/用户/可用性>
**可能性**：高/中/低　**可检测性**：可观测/难观测
**处置建议**：<修复/缓解/接受（需人类批准）/上报>
**状态**：待决策 / 已缓解 / 已接受（批准人 <…>，时间 <…>）
```

## 6. MICRO — 极小任务的简版回复（仍须解释与证据）

```markdown
**改了什么**：`file:line` —— <一句语义>
**为什么**：<根因一句>
**验证**：`<命令>` → `<真实结果>`
**不确定**：无 / <具体项>
**等级**：R<?>
```

## 7. 开场三行（每次任务开头，常驻规则要求）

```
[ADPP] 任务：<一句话>｜类型：<…>｜等级：R<?>｜停止条件：无 / STOP-<n>
[ADPP] 只读阶段：读 <入口/文件> → 输出 已知/未知/假设/风险 四清单 + 计划
[ADPP] 本轮不改代码（除非 R0/R1 且计划已输出，或已获明确确认）
```
